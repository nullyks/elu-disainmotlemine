# Disainmõtlemine, 3D modelleerimine ja robootika

Tallinna Ülikooli ELU projekti tutvustav veebileht, millel on avaleht ja neli ühesuguse ülesehitusega rühmalehte. Sisu põhineb [ELU projekti kirjeldusel](https://elu.tlu.ee/et/projektid/disainmotlemine-3d-modelleerimine-ja-robootika-0) ja rühmade töödokumentidel.

[Ava veebileht GitHub Pagesis](https://nullyks.github.io/elu-disainmotlemine/)

Veebilehe failid on kataloogis `docs/`. Kohalikuks eelvaateks ava `docs/index.html` brauseris või käivita repositooriumi juurkaustas `python -m http.server 8000 --directory docs`.

GitHub Pages avaldab kataloogi `docs/` harust `main`.

[Veebilehe loomise näidisprompt](PROMPT.md)
